# Qwen Media Skills

让你的 Agent 能听懂音频、看懂视频。

这套 Skills 适用于支持自定义 Skill、工具或脚本的 Agent 软件。接入后，Agent 可以根据你的自然语言意图，自动选择合适的能力来处理媒体文件。

## 它能做什么？

你可以直接这样说：

- “提取这个视频的口播稿”
- “把这段录音转成文字”
- “识别视频里的人说了什么”
- “这个视频讲了什么？”
- “帮我拆解这个视频的详细分镜”
- “先提取口播稿，再分析视频画面”

它支持音频和视频转文字、口播稿与台词提取、带时间戳的语音转写、视频总结、视频问答，以及分镜和镜头分析。

## 怎么用？

把本仓库中的 Skills 安装到你的 Agent 软件中，然后配置 Qwen / DashScope API Key。安装完成后，直接用自然语言描述需求即可。

Agent 会根据你的意图选择：

- 语音相关任务 → Qwen ASR
- 画面理解、总结和分镜任务 → Qwen Omni
- 同时需要语音和画面分析 → 两者组合调用

你不需要记住命令，也不需要因为输入文件是 MP4 就手动选择视频模型。

## 让 AI 帮你安装

如果你不确定自己的 Agent 软件该怎么安装，可以把下面这段提示词直接复制给它：

```text
请帮我安装这个公开仓库中的媒体处理 Skills：

https://github.com/yyxxd/qwen-media-skills

请先判断你当前支持哪种 Skill、工具或脚本安装方式，再选择兼容的方式安装。需要安装的内容包括：

- qwen-asr：音频和视频语音转写
- qwen-omni：视频理解、总结和分镜分析
- qwen-media-runtime：两个 Skill 共用的运行时

安装完成后，请检查 Node.js、FFmpeg 和 FFprobe 是否可用，并告诉我还缺少哪些依赖。

请不要索要、打印、保存或提交我的 API Key。API Key 只应通过安全的环境变量或该 Agent 支持的凭据配置保存。

安装后请用一个本地媒体文件做一次不产生实际模型调用的配置检查，并告诉我如何使用自然语言调用这些能力。
```

这段提示词适用于能够读取 GitHub 仓库并安装自定义 Skill 的 Agent。不同 Agent 的安装目录和配置方式可能不同，AI 会根据当前软件的能力选择对应方式。

## 示例

> 提取这个视频的口播稿。

> 这个视频讲了什么？请总结主要内容。

> 把这个视频拆解成详细分镜，包含时间、画面、人物动作和字幕。

> 先提取这个视频的口播稿，再分析它的画面和分镜。

## 包含哪些内容？

- `qwen-asr/`：语音转写能力
- `qwen-omni/`：视频理解能力
- `qwen-media-runtime/`：共享运行时、媒体检测、费用控制和上传处理

## 使用前准备

需要准备 Node.js 18+、FFmpeg、FFprobe 和阿里云百炼 DashScope API Key。

```powershell
$env:DASHSCOPE_API_KEY = "your-api-key"
```

请不要把 API Key 写入代码或提交到 Git 仓库。

## 技术说明

### 意图路由

- 转写、口播、台词、旁白 → Qwen ASR
- 总结、理解、问答、分镜、镜头分析 → Qwen Omni
- 复合请求 → 按任务共享预算并调用多个能力
- 仅提供媒体文件、没有处理要求 → 不自动调用模型

### 输入方式

- 小型媒体优先使用 Base64
- 已验证的临时上传链路可以处理较大本地文件
- 更大的文件可以提供可访问的 HTTPS URL 或正式 OSS 地址

### 费用控制

多个能力可以共享同一个任务预算。运行时会先估算费用，再决定是否自动执行，避免每个 Skill 各自使用独立预算。

### 输出安全

普通输出只展示使用的能力、媒体时长、本次费用和处理结果。Token、Authorization、Endpoint、完整 OSS 地址等诊断信息不会出现在普通输出中。
