还没有账号？带我开通
  1. 打开阿里云百炼官方控制台，自行注册或登录。
  2. 选择北京地域，按官方提示开通模型服务。实名验证和付款由你本人完成。
  3. 在“API Key / 密钥管理”创建服务密钥，复制到下面。找不到时，回到 Agent 说“带我连接百炼”。不要把密钥发到聊天里。

新密钥保存为当前用户的 DASHSCOPE_API_KEY 环境变量，并非加密存储。本工具会立即使用；其他已运行软件可能需要重新打开。
